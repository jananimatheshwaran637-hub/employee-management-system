# Employee Management System

A Django based Employee Management System with MySQL database.

## Features

- User Login Authentication
- Dashboard
- Add Employee
- View Employee Details
- Update Employee
- Delete Employee
- Employee Image Upload
- Bootstrap Responsive UI

## Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS
- Bootstrap

## Installation

Clone the repository

Install requirements

Run migrations

Start server:

python manage.py runserver
